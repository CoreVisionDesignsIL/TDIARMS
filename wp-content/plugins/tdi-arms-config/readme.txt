Essential configuration plugin for TDI Arms website. Sets up WooCommerce, SEO, security, and performance optimizations for tactical weapons accessories e-commerce platform.

== Description ==

TDI Arms Configuration is a specialized plugin designed to configure and optimize the TDI Arms tactical weapons accessories website. It provides essential features for WooCommerce integration, custom product fields, tactical-specific functionality, and performance optimizations.

== Key Features ==

* **WooCommerce Integration**: Optimized setup for tactical weapons accessories
* **Custom Product Fields**: Tactical grade, platform compatibility, specifications
* **Performance Optimizations**: Enhanced site speed and user experience
* **Security Enhancements**: Additional security measures for e-commerce
* **SEO Optimizations**: Built-in SEO enhancements for tactical industry
* **Dealer Portal Features**: B2B functionality for dealers and distributors
* **AJAX Functionality**: Dynamic product loading and quick view
* **Responsive Design**: Mobile-optimized tactical interface

== Custom Features ==

* **Tactical Product Information**: Specialized fields for weapon accessories
* **Platform Compatibility**: AK/AR/Universal platform categorization
* **Military Grade Indicators**: Professional use certifications
* **Technical Specifications**: Detailed product specifications
* **Installation Guides**: Integrated video and PDF resources
* **Quick Product View**: AJAX-powered product previews
* **Enhanced Search**: Tactical-specific search functionality

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/tdi-arms-config` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Configure the plugin settings on the 'TDI Arms Config' page in the WordPress admin

== Configuration ==

After activation, configure the plugin by navigating to:
*Settings → TDI Arms Config*

Key configuration options:
* Enable Tactical Features
* Enable Dealer Portal
* Product Display Settings
* Security Options

== Product Configuration ==

For each product, configure tactical-specific information:
1. Edit product in WordPress admin
2. Go to "Tactical Info" tab:
   * Mark as Tactical Grade
   * Set Platform Compatibility
   * Enable Military Use indicator
3. Go to "Specifications" tab:
   * Enter technical specifications
   * Add installation guide URL
   * Set material and finish information

== Frequently Asked Questions ==

= Does this plugin work with any theme? =

This plugin is specifically designed for the TDI Arms child theme but includes compatibility features for most WooCommerce-compatible themes.

= Can I customize the tactical fields? =

Yes, the plugin provides hooks and filters to customize tactical product fields and display options.

= Is the dealer portal secure? =

Yes, the dealer portal includes multiple security layers including role-based access control, secure authentication, and data validation.

= Does this plugin affect site performance? =

No, the plugin includes performance optimizations and lazy loading to ensure minimal impact on site speed.
